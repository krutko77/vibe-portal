- **2026-08-26 — саппорт: у ученика (admin, krutko77) не подключался
  десктопный VS Code по SSH к `vibe-krutko77`.** Ошибка `Extension

  `0.126.0` ломает резолвер (публичный баг-трекер, закрывался 25.08, вернулся
  26.08 с тем же релизом — см. github.com/microsoft/vscode issue #329735 и
  github.com/microsoft/vscode-remote-release issue #11810). Диагностировали
  вслепую (перепробовали переустановку расширения, `--enable-proposed-api`,
  откат самой VS Code 1.134.0→1.133.0 — не помогло, т.к. дело было не в
  редакторе), затем нашли первопричину через комментарии к issue. Фикс:
  `code --uninstall-extension ms-vscode-remote.remote-ssh` →
  `code --install-extension ms-vscode-remote.remote-ssh@0.124.0 --force`,
  плюс вручную выключить «Автоматическое обновление» у этого расширения
  (иначе само перетянет обратно на баганную 0.126.0). Подключение
  восстановлено, проверено практически. **Если у других учеников на десктопе
  всплывёт та же ошибка** — сразу нужен этот же фикс (версия расширения, не
  сервер), тратить время на диагностику заново не надо.
  Следом тот же пользователь (после переустановки расширения через

  «Открыть с помощью Code» — ответ дан устно (переустановщик VS Code
  user-setup поверх текущей версии с отмеченными галочками контекстного
  меню), это чисто клиентский Windows-вопрос, к vibe-portal отношения не
  имеет, действий на сервере не потребовалось.
