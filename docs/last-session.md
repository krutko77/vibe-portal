## Ключевые решения
- **Playwright — как MCP-сервер, не как файловый skill.** Запрошенный
  репозиторий технически не содержит skill-формата (`SKILL.md`) — только
  `.mcp.json`. Решение подтверждено пользователем через `AskUserQuestion`,
  а не принято агентом самостоятельно.
- **Superpowers — только скиллы, без хука `session-start`.** Хук меняет
  поведение Claude на принудительную проверку скиллов перед любым действием
  во всём проекте — расценено как слишком инвазивное для простой просьбы
  «установи скилл». Пользователь подтвердил этот вариант явно, когда были
  предложены три варианта (только скиллы / полный плагин с хуком /
  уточнить, какой именно скилл).
