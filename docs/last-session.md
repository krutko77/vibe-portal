## Подводные камни
- Хелпер `api()` в `app.js` сам делает `JSON.stringify(opts.body)` — при
  добавлении новых вызовов передавать в `body` обычный объект, а не уже
  сериализованную строку (в этой сессии словили именно такой баг в двух
  новых вызовах, исправлено).
- Ключи `registry.json` для `deploy-service` обязаны дословно совпадать с
  именем папки проекта (`<owner>::<папка>`) — иначе статус «РАБОЧИЙ» не
  подхватится молча, без ошибки. Проверять `ls` папки против ключей реестра
  при любой ручной правке.
- `vibe-panel` — сервис, которым пользователь может активно пользоваться в
  браузере в моменте; рестарт без явного текущего разрешения уже один раз
  был отклонён пользователем — всегда спрашивать перед `systemctl restart
  vibe-panel`, даже если изменения кажутся безобидными.
