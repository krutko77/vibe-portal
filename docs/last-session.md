## Ключевые решения
- **Никаких прямых запросов с портала к Claude/Anthropic** — только через
  прокси из `proxy.env` (требование пользователя).
- **Fail-closed, а не фолбэк:** без `HTTPS_PROXY` статус выключается, а шим
  не стартует вовсе — лучше явная поломка с причиной в журнале, чем тихий
  прямой выход.
- Выключатель статуса оставлен (`CLAUDE_STATUS_ENABLED=0`), но по умолчанию
  включено.

## Подводные камни
- **Шим без `HTTPS_PROXY` не стартует** — если прокси упадёт или пропадёт из
  `/data/config/env/proxy.env`, Claude у учеников ляжет целиком.
  Диагностика: `journalctl -u anthropic-shim -n 20 --no-pager` (FATAL) и
  `curl -x <proxy> https://api.anthropic.com`.
- Прокси должен пускать CONNECT к `api.anthropic.com`, `platform.claude.com`
  (шим) и `status.claude.com` (панель) — при смене прокси проверить все три.
- Рестарт `anthropic-shim` рвёт активные стримы учеников — перед рестартом
  смотреть `ss -tn state established '( sport = :8190 )'`.
- Node 22 встроенный `fetch` игнорирует `HTTPS_PROXY` — любой новый
  исходящий запрос в панели/шиме делать через `undici` `ProxyAgent`.
