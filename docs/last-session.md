## Ключевые решения
- **Редизайн ограничен строго графиком CPU, с отдельным рендер-пайплайном.**
  Пользователь явно написал «нагрузки CPU» — RAM-график (`renderVpsChart`)
  сознательно не тронут, чтобы не было риска регресса уже рабочей части;
  вместо модификации общей функции сделана отдельная `renderVpsCpuChart()`
  специально под раскладку Timeweb (другая сетка осей, другой набор
  контролов).
- **Цвет акцента дропдаунов — оставлен родной frost-blue портала
  (`--primary`), не фиолетовый Timeweb.** Не было явного запроса пользователя
  точно скопировать цвет — решено, что внутренняя консистентность UI портала
  важнее точного попиксельного совпадения с чужим вендорским дашбордом. Это
  решение агента, пользователем не подтверждено и не оспорено.
- **«Автоматическая шкала» сделана по-настоящему функциональной**
  (`vpsCpuNiceMax()` пересчитывает верхнюю границу под реальный максимум),
  хотя ни на одном скриншоте не было явно видно, как выглядит авто-режим —
  решено, что рабочий, но не на 100% точно угаданный по виду тумблер лучше
  декоративного нерабочего.
