## Ключевые решения
- По `/var/log/btmp`/`btmp.1` пользователю явно предложен выбор (обрезать
  оба / обрезать только активный / не трогать), т.к. это security-лог
  (история неудачных попыток входа), а не обычный кэш — удаление без
  подтверждения могло бы стереть потенциально полезную для расследования
