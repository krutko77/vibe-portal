## Ключевые решения
- Объём удаления (пункт B) — «целиком», не частично: пользователь трижды
  явно подтвердил полный снос функционала (UI + backend + проксирование +
  документация), а не только визуальное скрытие кнопок. Решено брать
  именно эту трактовку по умолчанию при похожих формулировках в будущем.
- `resolvePublishTarget()` → `resolveProjectTarget()`: функция была общим
  хелпером проверки владения проектом, используемым и publish-роутами, и
  несвязанной фичей «раздел проекта» — переименована, а не удалена, чтобы
  не сломать `POST /api/projects/:name/section`.
- Студенческий multi-tenant код **не трогался** намеренно — слишком широкий
  и неоднозначный объём для правки без явного скоупинга, особенно учитывая
  что `CLAUDE.md` прямо маркирует auth/изоляцию контейнеров как
  критическую зону. Решение оставлено пользователю на будущее.
- `/data/config/vscode-server/krutko77` не чистился, хотя это
  единственный по-настоящему крупный кэш на диске (998М) — пользователь
  предпочёл не терять переустановку VS Code server при следующем
  подключении ради экономии места.
