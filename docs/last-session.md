## Ключевые решения
- **Статус виден всем залогиненным, не только admin** — данные публичные,
  ученику полезно понимать, что проблема у Anthropic, а не у него.
- **status.claude.com — напрямую, без HTTPS_PROXY**: прокси из `proxy.env`
  отвечает 403 на CONNECT к этому хосту, а напрямую — 200. Node `fetch`
  прокси из env и так не использует, поэтому никакого кода для обхода нет.
- **Один источник SVG логотипа** — в чипе навбара; модалка его клонирует.
