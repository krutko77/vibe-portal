## 2026-10-01

- **Новая модалка «VPS РФ»: диск + графики нагрузки CPU/RAM.** Кнопка на
  панели открывает модалку с диском (прогресс-бар total/used/avail) и
  двумя графиками — CPU и RAM. Архитектурный разворот по ходу сессии (по
  прямому указанию пользователя): вместо своего сэмплера с периодическим
  опросом — забор истории напрямую из API Timeweb Cloud в момент открытия
  модалки, т.к. хостинг уже копит эти данные сам. `panel/lib/vps-metrics.js`
  (новый файл) дёргает `GET /servers/{id}/statistics` (RAM, старый
  endpoint) и `GET /servers/{id}/statistics/{time_from}/{period}/{keys}`
  (CPU — на этом сервере старый endpoint отдаёт пустой `cpu[]`).
  Найденные по дороге особенности API: поля snake_case
  (`logged_at`/`used_cached`), `time_from` в CPU-эндпоинте — это ПРАВАЯ
  граница окна (период отсчитывается назад от неё, не вперёд), диск нужно
  брать не локальным `statfs(/)`, а из `GET /servers/{id}` →
  `disks[0].size/used` (statfs давал заниженное число из-за служебных
  EFI/boot-партиций — расходилось с дашбордом самого Timeweb). Токен
  (`TIMEWEB_API_TOKEN`) живёт в `/data/config/env/vibe-panel.env`, Claude
  его не видел и не запрашивал.
