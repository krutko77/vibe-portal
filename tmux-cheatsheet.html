tmux — шпаргалка

Префикс = Ctrl+b  (на Mac — клавиша Control ⌃, не ⌘). Нажать → отпустить → потом команду.

Сессии

tmux
запустить
tmux new -s admin
создать с именем
tmux ls
список сессий
tmux attach
вернуться (из обычной строки)
tmux a -t admin
вернуться в нужную
Ctrl+b  d
свернуть (всё продолжит работать)
Ctrl+b  s
переключить сессию изнутри
Ctrl+b  $
переименовать сессию

Удалить сессии

kill-session -t 0
убить одну (tmux …)
kill-session -a
убить все, кроме текущей
kill-server
убить вообще все

Окна (как вкладки)

Ctrl+b  c
новое окно
Ctrl+b  n / p
следующее / предыдущее
Ctrl+b  0…9
перейти к окну №
Ctrl+b  w
список окон (выбор)
Ctrl+b  ,
переименовать окно
Ctrl+b  &
закрыть окно

Панели (split)

Ctrl+b  %
разделить ↔ (Shift+5)
Ctrl+b  "
разделить ↕ (Shift+')
Ctrl+b  ←↑↓→
перейти в панель
Ctrl+b  z
панель на весь экран / обратно
Ctrl+b  x
закрыть панель (y)

mc / nnn — файлы

mc
двухпанельный менеджер
nnn
однопанельный (q — выход)
↑ ↓ / Enter
ходить / открыть папку
Tab
сменить панель (mc)
F3 / F10
смотреть файл / выйти (mc)
💡 Файлы смотреть в менеджере, открывать/править — словами через Claude в соседней панели.
