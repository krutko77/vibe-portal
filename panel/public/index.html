VIBE PORTAL · ИНСТРУКЦИЯ

Как работать с порталом

Пошаговый гайд: что где находится, как создать проект, как открыть VS Code и где Claude.

Вход Навбар VS Code Проекты Создание проекта Чат Claude Файлы Контейнер
1. ВХОД В ПОРТАЛ

Портал живёт на vibe.kiselevgroup.com. Если ты уже зарегистрирован — нажми «Войти →», введи логин и пароль. Если ты новый ученик — попроси администратора создать тебе аккаунт.

2. НАВБАР

В шапке: KG — логотип, 4 таба (VS Code, Проекты, Курс, Материалы), справа — кнопки Claude, тема, история, настройки.

3. VS CODE

На таб’е «VS Code» — большая серая кнопка «Открыть → VS Code». Слева от неё — состояние контейнера (Вкл/Выкл) с таймером авто-стопа.

4. ПРОЕКТЫ

Таблица: Тип, Статус, Название, Автор, Дата, Действия. По кнопкам: 📁 Файлы, CLAUDE (чат по проекту), VS Code, 🗑 Удалить (в архив .deleted/).

5. СОЗДАНИЕ ПРОЕКТА

Две кнопки сверху: + Пустой (пустая папка) и + Шаблон (выбор из двух базовых шаблонов).

6. ЧАТ С CLAUDE

В строке проекта — кнопка CLAUDE. Открывается левая панель: сессии, выбор модели (sonnet/opus), история, attachments. Справа сверху — общий помощник Claude (по всему workspace).

7. ФАЙЛЫ

Кнопка 📁 в строке проекта — открывает встроенный просмотрщик файлов. Дерево слева, содержимое справа.

8. КОНТЕЙНЕР

У тебя свой Docker-контейнер (1.5GB RAM / 1 CPU). Авто-останавливается через 30 мин простоя. Таймер виден сверху. Workspace сохраняется — следующий клик «Открыть VS Code» подымет контейнер за 2–4 сек.

VIBE PORTAL · АРХИТЕКТУРА

Как устроен портал

Высокоуровневая схема: где что живёт, как изолированы ученики, через что ходит Claude.

Обзор Контейнеры Anthropic shim Изоляция
1. ОБЗОР

Каждый ученик работает в своём изолированном Docker-контейнере. Внутри — code-server (VS Code в браузере) + Claude Code CLI. Через nginx на хосте проксируется и UI портала, и сам VS Code.

2. КОНТЕЙНЕРЫ

Образ vibe-workspace:dev (Debian 12 + Node 22 + code-server). Каждый ученик получает имя vibe-<login>, порт 8200+. Маунты: workspace (rw), templates (ro), extensions (shared rw), skills (shared ro).

3. ANTHROPIC SHIM

Из контейнера Claude CLI ходит не напрямую в api.anthropic.com, а через локальный shim на 172.30.0.1:8190. Шим подменяет токен на реальный OAuth и форвардит запрос.

4. ИЗОЛЯЦИЯ

iptables-правила (chains VIBE-FILTER + VIBE-INPUT) запрещают контейнерам видеть друг друга, ходить в private RFC1918 и до хостового loopback. Можно только наружу в интернет и в шим.

VIBE PORTAL · CLAUDE CODE

Claude Code и команды

Список slash-команд, советы по промптам, особенности работы в порталe.

Команды Промпты Память Контекст
1. КОМАНДЫ
КомандаЧто делает
/initСоздаёт CLAUDE.md в проекте с автоопределённой архитектурой.
/compactСжимает контекст: удаляет старые сообщения, оставляя суть.
/clearПолностью очищает контекст. Используй при смене темы.
/diffПоказывает что Claude изменил с последней проверки.
/usageСколько токенов и денег потрачено в сессии.
/explainПодробное объяснение кода без правки.
/skillВызвать конкретный установленный скилл (superpowers / memory / ui-ux).
2. ХОРОШИЕ ПРОМПТЫ
  • Контекст сначала — что за проект, что уже сделано, что не получилось.
  • Чёткая задача — что должен сделать Claude и какой результат ждёшь.
  • Ограничения — какие файлы трогать нельзя, что не использовать.
  • Не пиши «как обычно» — Claude не знает что у тебя обычно. Опиши явно.
3. ПАМЯТЬ

Используй скилл claude-memory: один .md файл в .claude/memory/ — учится от исправлений, ловит противоречия, чистит дубли. Запускается командой /memory update.

4. КОНТЕКСТ И СЕССИИ

Сессии чата Claude хранятся в /root/.claude/projects/-data-vibe-students-<user>-<project>/. В портале они доступны через dropdown «сессии». Можно создавать новые, удалять, переключаться между ними.

VIBE PORTAL · FAQ

FAQ · Решение проблем

Типовые ситуации и как из них выбраться.

«Открыть VS Code» открыло пустую страницу

Контейнер только что запустился — code-server поднимается ~2 сек. Закрой вкладку и нажми снова. Если опять — обратись к админу.

Claude отвечает «Please run /login» или «401»

Токен на хосте устарел и не обновился. Подожди 5 минут — sync-таймер делает обновление каждые 5 мин. Если не помогло — пингуй админа.

Контейнер всё время выключается

Idle-reaper: 30 мин без heartbeat → stop. Держи вкладку портала открытой — UI шлёт heartbeat каждую минуту.

Удалил файлы — можно восстановить?

Если делал git commit — да, git checkout HEAD~ -- <file>. Если нет — увы. Совет: commit'ить после каждого крупного шага.

Claude забывает контекст

Используй скилл claude-memory: /memory update в чате — сохранит ключевые моменты. Или открой новую сессию из чата проекта в портале (история в портале сохраняется).
