01

Начало

Vibe — это твой персональный рабочий портал курса. У тебя есть изолированный Docker-контейнер, в нём — VS Code в браузере, Claude Code и общие шаблоны курса.

Что у тебя есть

01
Свой workspace
Папка /home/student/workspace/ — твоя, никто кроме тебя её не видит. Здесь живут все твои проекты.
02
VS Code в браузере
Полноценный редактор кода — открывается кнопкой «Открыть VS Code» в шапке.
03
Claude (два варианта)
Чат с Claude прямо в портале по проекту (слева) и общий помощник (справа). Плюс Claude Code в терминале VS Code.
04
Шаблоны курса
Готовые курсовые приложения (read-only) в /home/student/templates/. Скопируй и работай.

Первый шаг

  1. Нажми «+ Шаблон» и выбери Шаблон для Битрикс24 + VibeCode.
  2. Введи имя проекта (латиница, дефис) — например, my-first-app.
  3. Открой проект в VS Code → терминал → запусти claude.
  4. Прочитай CLAUDE.md в корне проекта — там пошаговый онбординг.
Контейнер останавливается через 30 мин простоя. Это нормально — workspace остаётся, при следующем клике на «Открыть VS Code» всё восстановится за 2–4 секунды. Сверху в шапке виден таймер до автозакрытия.

Работа с Клодом

В Клоду можно обратиться тремя способами: в портале (чат по проекту), в общем помощнике (справа в navbar) и из терминала VS Code (claude).

Команды Claude Code

КомандаЧто делает
/initСоздаёт CLAUDE.md в текущем проекте с автоопределённой архитектурой.
/compactСжимает контекст: удаляет старые сообщения, оставляя суть.
/clearПолностью очищает контекст. Используй когда сменил тему.
/diffПоказывает что Claude изменил с последней проверки.
/usageСколько токенов и денег потрачено в сессии.
/explainПодробное объяснение кода без правки.

Как писать промпты

  • Контекст сначала — что за проект, что уже сделано, что не получилось.
  • Чёткая задача — что должен сделать Claude, какой результат ждёшь.
  • Ограничения — какие файлы трогать нельзя, что не использовать.
  • Не пиши «как обычно» — Claude не знает что у тебя обычно. Опиши явно.

FAQ · Решение проблем

«Открыть VS Code» — открылось, но ничего не работает

Контейнер только что запустился — code-server поднимается ~2 сек. Если страница пустая, закрой вкладку и нажми «Открыть VS Code» снова.

Claude отвечает «Please run /login» или «401»

Иногда токен надо обновить. Подожди 1–2 минуты — портал делает это автоматически каждые 5 минут. Если не помогло — обратись к админу.

Удалил файлы случайно — можно восстановить?

В терминале VS Code: git log в проекте → если коммитил, легко вернуть. Если не коммитил — увы. Совет: git commit после каждого крупного изменения.

Контейнер всё время выключается

Это idle-reaper — 30 мин без активности → stop. Сверху в шапке показывает таймер. Heartbeat от UI продлевает — держи вкладку портала открытой.

Claude забывает контекст

Используй скилл claude-memory: он структурно ведёт .claude/memory/ в проекте. Или начни новую сессию из чата проекта в портале (там история сохраняется).
