# Объясни структуру .claude

Это учебная команда. Задача — наглядно объяснить устройство папки `.claude`
этого проекта.

Аргумент (если задан): **$ARGUMENTS** — если указана конкретная сущность
(`skills`, `commands`, `agents`, `hooks`, `mcp`, `settings`, `output-styles`),
сфокусируйся на ней.

## Что сделать

1. Прочитай дерево `.claude/` (через `Glob` по `.claude/**` и/или `ls`).
2. Прочитай `CLAUDE.md` в корне проекта.
3. Объясни простыми словами по каждой сущности:
   - **что это**, **где лежит**, **в каком формате**, **когда срабатывает**;
   - приведи пример из этого проекта.
4. Заверши памяткой «как добавить свою сущность» (новый скилл / команду / хук / MCP).

## Формат ответа

- Сначала короткое дерево папки `.claude`.
- Затем по разделу на каждую сущность: **Что → Где → Пример → Как добавить**.
- Без воды, по-русски, с указанием путей вида `.claude/commands/имя.md`.
