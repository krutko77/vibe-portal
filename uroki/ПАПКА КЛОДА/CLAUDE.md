# Учебный проект: структура папки `.claude`

> **Назначение.** Это **учебный** проект. Он не делает «настоящего» продукта — его
> цель показать, **как устроена папка `.claude`** в Claude Code: из каких сущностей
> она состоит, за что каждая отвечает и как добавить свою. По этому проекту удобно
> рассказывать другим, как собирается конфигурация Claude.

Файл `CLAUDE.md` — это «память проекта»: Claude Code автоматически подгружает его в
контекст в начале каждой сессии. Сюда пишут правила, договорённости и контекст,
которые модель должна знать всегда.

---

## Что лежит в этом проекте

```
ПАПКА КЛОДА/
├── CLAUDE.md                     ← этот файл (память/правила проекта)
├── index.html                    ← наглядная страница: структура + установка MCP
├── .mcp.json                     ← подключённые MCP-серверы (общие для команды)
└── .claude/
    ├── settings.json             ← настройки проекта (права, хуки, MCP-тумблеры)
    ├── settings.local.json.example ← пример личных настроек (не коммитится)
    ├── skills/                   ← навыки (skills)
    │   ├── superpowers/          ← набор процессных скиллов SuperPowers
    │   └── ui-ux-pro-max/        ← скилл UI/UX Pro Max (дизайн-интеллект)
    ├── commands/                 ← кастомные слэш-команды
    │   ├── prototype-first.md    ← «всё через прототип в Pencil, потом код»
    │   └── explain-claude.md     ← объясняет структуру .claude
    ├── agents/                   ← субагенты
    │   └── ui-prototyper.md      ← узкий субагент для сборки .pen-прототипов
    ├── hooks/                    ← хуки (срабатывают на события)
    │   └── session-start.sh      ← печатает памятку в начале сессии
    └── output-styles/            ← стили вывода
        └── tutor.md              ← режим «Наставник»
```

## Сущности папки `.claude` — кратко

| Сущность | Где | Что делает |
|---|---|---|
| **CLAUDE.md** | корень / `~/.claude/` | Память и правила. Грузится в контекст всегда. |
| **skills** | `.claude/skills/<имя>/SKILL.md` | Навыки: переиспользуемые инструкции «как делать X». Вызываются по запросу. |
| **commands** | `.claude/commands/<имя>.md` | Слэш-команды (`/имя`). Шаблон запроса с frontmatter. |
| **agents** | `.claude/agents/<имя>.md` | Субагенты со своим набором инструментов и контекстом. |
| **hooks** | `.claude/hooks/` + `settings.json` | Скрипты на события (SessionStart, PreToolUse…). Запускает сам harness. |
| **output-styles** | `.claude/output-styles/<имя>.md` | Меняют манеру ответов Claude. |
| **MCP** | `.mcp.json` | Внешние серверы инструментов (Figma, Pencil, Playwright…). |
| **settings** | `.claude/settings.json` | Права (permissions), env, хуки, тумблеры MCP. |

> Полный, «человеческий» разбор каждой сущности с примерами — открой **`index.html`**
> в браузере или вызови команду **`/explain-claude`**.

## Правила работы в этом проекте

1. **Сначала прототип.** Любая задача по UI/сайту делается через команду
   **`/prototype-first`**: сначала прототип в Pencil (`.pen`), показ пользователю,
   и только после одобрения — код. Напрямую «руками в код» интерфейс не верстаем.
2. **Дизайн — через скилл.** Перед версткой подключаем `ui-ux-pro-max`
   (стиль + палитра + шрифты + UX-паттерны).
3. **Секреты — мимо репозитория.** Токены (например `FIGMA_API_KEY`) только через
   переменные окружения, не в `.mcp.json` и не в `CLAUDE.md`.

## Подключённые MCP-серверы

См. `.mcp.json`. Подключены (как пример): **figma**, **pencil**, **playwright**,
**context7**. Инструкция по установке и получению токена — в `index.html`.
