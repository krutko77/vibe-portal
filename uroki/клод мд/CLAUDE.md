# Сайт-шпаргалка: «.md и CLAUDE.md»

Учебный сайт-шпаргалка для **новичков без опыта в коде**. Объясняет простыми
словами, что такое Markdown-файл (`.md`) и зачем нужен файл `CLAUDE.md`.
Потом сайт переносится на «вайб-портал» автора.

## Как запускать

- Открыть `index.html` двойным кликом в браузере — всё работает без установки
  и без сборки. Зависимостей нет.

## Структура проекта

- `index.html` — единственная страница со всеми разделами.
- `assets/css/styles.css` — все стили.
- `assets/js/script.js` — подсветка активного пункта меню, мобильное меню,
  кнопки «Копировать».

## Стиль и тон

- Все тексты — **на русском**, дружелюбно и максимально просто.
- Минимум жаргона. Сложные вещи объясняем через аналогии.
- Дизайн: чистый минимал в духе Notion. Белый фон, мягкие серые тона,
  много воздуха, один акцентный цвет — индиго `#4f46e5`.
- Боковое меню слева; на телефоне сворачивается в кнопку-гамбургер.

## Чего избегать

- Не добавлять сборщики, фреймворки и внешние библиотеки — только чистые
  HTML, CSS и JS.
- Не вводить тёмную тему, поиск, бэкенд и лишние анимации.
- Не усложнять код: его должен понимать новичок.
- Не ломать лёгкость переноса — проект должен открываться простым кликом.
