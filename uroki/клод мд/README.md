# Шпаргалка: .md и CLAUDE.md

Простой учебный сайт для новичков: что такое Markdown-файл (`.md`) и зачем нужен `CLAUDE.md`.

## Запуск

Откройте `index.html` двойным кликом в браузере. Установка и сборка не нужны.

## Структура

```
.
├── index.html              # страница со всеми разделами
├── assets/
│   ├── css/styles.css      # стили
│   └── js/script.js        # меню и кнопки «копировать»
├── CLAUDE.md               # записка для ИИ-помощника о проекте
└── README.md
```

## Перенос

Это статический сайт без зависимостей — просто скопируйте все файлы на свой портал.
