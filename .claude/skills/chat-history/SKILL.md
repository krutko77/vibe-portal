# История чата

Экспортирует диалог из транскрипта Claude Code (`~/.claude/projects/<slug>/<session>.jsonl`)
в читаемый `.md`: только реальные реплики пользователя и ассистента, `thinking` и
`tool_result` выброшены, `tool_use` свёрнут в короткую сводку вида
`_(инструменты: Bash ×3, Write)_`.

Скрипт `export-history.mjs` лежит рядом с этим файлом — вызывать его абсолютным путём.
Запускать **из корня проекта** (`/opt/vibe-portal`), т.к. он резолвит транскрипты и
выходную папку от `process.cwd()`.

## Команды

```bash
# Текущая сессия (по умолчанию — из $CLAUDE_CODE_SESSION_ID)
node <skill-dir>/export-history.mjs

# Конкретная сессия по id
node <skill-dir>/export-history.mjs --session <id>

# Все сессии проекта разом
node <skill-dir>/export-history.mjs --all

# Список сессий (id, дата, первая реплика) — чтобы выбрать нужную
node <skill-dir>/export-history.mjs --list
```

Каждая экспортированная сессия пишется в
`.claude/chat-history/<YYYY-MM-DD>-<session-id-8>.md` (папка создаётся
автоматически). Скрипт печатает в stdout путь(и) к сохранённым файлам.

## Когда что использовать

- «Сохрани этот чат» / «запиши историю» → без флагов (текущая сессия).
- «Сохрани все чаты» / «выгрузи всю историю» → `--all`.
- «Сохрани вчерашний разговор про X» → сначала `--list`, найти сессию по
  превью первой реплики или дате, затем `--session <id>`.

## После экспорта

Просто сообщи пользователю путь(и) к файлу(ам), который вывел скрипт. Не
пересказывай содержимое и не открывай файл заново — он уже читаемый Markdown.

`.claude/chat-history/` в `.gitignore` — это личный рабочий лог, а не часть
кодовой базы, в git не попадает и в бэкап-снапшот тоже (см. секцию «Бэкап» в
`/opt/vibe-portal/CLAUDE.md`, если понадобится расширить исключения).
