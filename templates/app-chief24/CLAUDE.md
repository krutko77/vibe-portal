# app-chief24 — Штаб руководителя отдела

Загрузка команды, статус проектов, подписанные акты и деньги — четыре вкладки одного экрана для руководителя отдела.

**Категория:** Управление · Дашборд
**Оценка часов:** ~16 часов
**Платформа:** Битрикс24 / Standalone

## Что это

Дашборд для руководителя отдела (РОПа, тимлида, начальника проектного блока): в один экран собрано то, ради чего обычно открывают пять вкладок Битрикс24. Загрузка людей, приоритеты проектов, объём подписанных актов, факт vs план продаж. Плюс табель времени и аналитика чат-центра.

## Что внутри шаблона

Это **демо-версия** приложения: рабочий UI + синтетические данные.
Бэкенда нет — фронтенд перехватывает все вызовы `/api/*` через `js/demo-shim.js`
и возвращает моки из `js/demo-data.js`. Открывается в браузере без сервера.

## Как открыть

1. На vibe-портале / dev-портале нажми «Создать из шаблона» → `app-chief24`.
2. В VS Code открой `index.html`.
3. Запусти через Live Server (расширение VS Code) или просто открой файл в браузере.

## Фичи (из исходного приложения)

- Загрузка сотрудников: % занятости, грейд, проекты по стадиям (ТЗ / Оплата / Настройка / Активные / Мелкие)
- Приоритеты проектов: канбан по людям с пометкой VIP/Перспективный/Стандарт
- Объём продаж и подписанных актов по месяцам — бары + детализация по сделкам
- Показатели месяца: план / факт / потенциал с разбивкой по сделкам в воронке
- Замечания недели: 5×7 сетка (день × сотрудник) + график за 3 месяца
- Благодарности от клиентов: накопительный счётчик и разбивка по неделям
- Табель времени: 8/Б/Н по дням, итог за месяц, заметки к причинам
- Аналитика диалогов в чат-центре: среднее время ответа, лучший/худший диалог по каждому

## Куда копать дальше

- `index.html` — структура страницы (вкладки/блоки)
- `js/app.js` — корень приложения, инициализация
- `js/demo-data.js` — генератор моков, можно править чтобы поиграться с цифрами
- `js/demo-shim.js` — перехват `fetch('/api/...')` для подмены ответов
- `css/` — стили (большинство в духе Битрикс24)

## Если хочешь сделать реальную интеграцию

Заменить `demo-shim.js` на бэкенд который ходит в Битрикс24 REST:

```
https://<portal>.bitrix24.ru/rest/<user_id>/<webhook_token>/
```

Подробности — на dev.kiselevgroup.com/wiki/ в разделе «Битрикс24 / REST API».
