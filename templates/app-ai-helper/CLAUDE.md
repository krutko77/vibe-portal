# app-ai-helper — AI-подсказчик возражений

Менеджер слышит возражение — AI за 2 секунды подсказывает ответ из вашей базы знаний, в стиле компании, со ссылками на документы.

**Категория:** AI · Продажи
**Оценка часов:** ~24 часа
**Платформа:** Битрикс24 / Standalone

## Что это

Прямо во время звонка менеджер видит подсказку: что ответить на «дорого», «уже работаем с другими», «пришлите КП». AI берёт ответы из вашей корпоративной базы знаний и формулирует в стиле компании. Источники — приложены.

## Что внутри шаблона

Это **демо-версия** приложения: рабочий UI + синтетические данные.
Бэкенда нет — фронтенд перехватывает все вызовы `/api/*` через `js/demo-shim.js`
и возвращает моки из `js/demo-data.js`. Открывается в браузере без сервера.

## Как открыть

1. На vibe-портале / dev-портале нажми «Создать из шаблона» → `app-ai-helper`.
2. В VS Code открой `index.html`.
3. Запусти через Live Server (расширение VS Code) или просто открой файл в браузере.

## Фичи (из исходного приложения)

- Live-подсказки: транскрипт звонка → AI распознаёт возражение → 3 варианта ответа за 2 секунды
- Ответы из вашей базы знаний — регламенты, скрипты, кейсы, прайс — а не «нагенерированный» текст
- Анализ записанных звонков: загружаешь транскрипт → AI находит возражения и оценивает работу
- База готовых отработок: 50+ возражений × 3-4 варианта на каждое, с категориями и поиском
- Лайки и метрики: команда отмечает, какие тейки работают — приложение учится
- Размещение в Битрикс24: открывается прямо в карточке звонка/сделки
- Поддержка GigaChat, OpenRouter, Anthropic — выбираете провайдера под бюджет

## Куда копать дальше

- `index.html` — структура страницы (вкладки/блоки)
- `js/app.js` — корень приложения, инициализация
- `js/demo-data.js` — генератор моков, можно править чтобы поиграться с цифрами
- `js/demo-shim.js` — перехват `fetch('/api/...')` для подмены ответов
- `css/` — стили (большинство в духе Битрикс24)

## Если хочешь сделать реальную интеграцию

Заменить `demo-shim.js` на бэкенд который ходит в Битрикс24 REST:

```
https://<portal>.bitrix24.ru/rest/<user_id>/<webhook_token>/
```

Подробности — на dev.kiselevgroup.com/wiki/ в разделе «Битрикс24 / REST API».
