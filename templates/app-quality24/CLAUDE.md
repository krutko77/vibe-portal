# app-quality24 — Контроль качества звонков

Кто из менеджеров проседает по качеству звонков, кто не заполняет CRM, как меняются оценки по неделям — в одном дашборде из вашей Google-таблицы.

**Категория:** ОКК · Дашборд
**Оценка часов:** ~10 часов
**Платформа:** Google Sheets / Битрикс24

## Что это

Дашборд для руководителя отдела контроля качества: видно, у кого падает % ОКК, кто не заполняет CRM, как меняются оценки по неделям. Источник данных — обычная Google-таблица, в которую аудиторы пишут разметку звонков.

## Что внутри шаблона

Это **демо-версия** приложения: рабочий UI + синтетические данные.
Бэкенда нет — фронтенд перехватывает все вызовы `/api/*` через `js/demo-shim.js`
и возвращает моки из `js/demo-data.js`. Открывается в браузере без сервера.

## Как открыть

1. На vibe-портале / dev-портале нажми «Создать из шаблона» → `app-quality24`.
2. В VS Code открой `index.html`.
3. Запусти через Live Server (расширение VS Code) или просто открой файл в браузере.

## Фичи (из исходного приложения)

- % ОКК и % заполнения CRM по каждому менеджеру с разбивкой по неделям
- Динамика отдела: общий тренд качества по неделям
- Разбивка по типам звонков (холодные / тёплые / входящие / Секретарь)
- Тепловая таблица «критерии × недели» — где конкретно проседаем
- Прозвон «Контактный хаб» 08:50–10:10 — кто отрабатывает утренний слот
- Звонки «Секретарь» с детализацией возражений и оценок аудитора
- Источник — ваша Google-таблица: правите разметку — дашборд обновляется

## Куда копать дальше

- `index.html` — структура страницы (вкладки/блоки)
- `js/app.js` — корень приложения, инициализация
- `js/demo-data.js` — генератор моков, можно править чтобы поиграться с цифрами
- `js/demo-shim.js` — перехват `fetch('/api/...')` для подмены ответов
- `css/` — стили (большинство в духе Битрикс24)

## Если хочешь сделать реальную интеграцию

Заменить `demo-shim.js` на бэкенд который ходит в Битрикс24 REST:

```
https://<portal>.bitrix24.ru/rest/<user_id>/<webhook_token>/
```

Подробности — на dev.kiselevgroup.com/wiki/ в разделе «Битрикс24 / REST API».
