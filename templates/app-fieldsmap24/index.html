Раскладка карточки

Нет ни одного портала

Жми «+ Новый портал» в шапке, добавь название и входящий вебхук — и редактируй раскладку карточек этого портала.

Новый портал

Б24 → Разработчикам → Другое → Входящий вебхук. Для работы редактора у вебхука должны быть отмечены права: CRM (crm) и Пользовательские поля (userfieldconfig). Демо: вебхук не проверяется, любой принимается.

Редактирование поля

Видно только в этой раскладке (и воронке, если выбрана). Сохраняется кнопкой «Сохранить» в шапке.
Меняется в самой сущности — повлияет везде, где видно это поле. Применится сразу.
Системное поле — переименовать через REST нельзя. Доступен только override для раскладки.
    Клик ✎ — переименовать, ✕ — удалить значение. Применится после «Применить». Удаление существующего значения освободит его в карточках, где оно было выбрано.

    Новое поле

    Должно начинаться с UF_, заглавные латинские буквы, цифры, _. Сгенерируется из названия — поправь, если нужно.

    Массовая заливка полей

    Принимает разделители — - : = →. Списки — через запятую/точку с запятой/слэш в скобках или после слова «список».
