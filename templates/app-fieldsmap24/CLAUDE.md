# app-fieldsmap24 — Конструктор карточек CRM

Меняйте раскладку полей в карточках Битрикс24 мышкой — создавайте секции, перетаскивайте поля, сохраняйте на портал. Без программистов.

**Категория:** CRM · Конструктор
**Оценка часов:** ~15 часов
**Платформа:** Битрикс24

## Что это

FieldsMap — внешнее приложение для Битрикс24. Подключаете один или несколько порталов по входящему вебхуку и мышкой редактируете раскладку карточек: создаёте секции, перетаскиваете поля, переименовываете, добавляете значения списков. Без задач программисту, без копий портала, без релизов.

## Что внутри шаблона

Это **демо-версия** приложения: рабочий UI + синтетические данные.
Бэкенда нет — фронтенд перехватывает все вызовы `/api/*` через `js/demo-shim.js`
и возвращает моки из `js/demo-data.js`. Открывается в браузере без сервера.

## Как открыть

1. На vibe-портале / dev-портале нажми «Создать из шаблона» → `app-fieldsmap24`.
2. В VS Code открой `index.html`.
3. Запусти через Live Server (расширение VS Code) или просто открой файл в браузере.

## Фичи (из исходного приложения)

- Drag-and-drop: переставляйте поля между секциями карточки
- Создание секций — по любому смыслу (Главное / О клиенте / Документы / Прочее)
- Несколько порталов в одном приложении: переключатель в шапке
- Создание новых пользовательских полей (UF) — одно или массово через текстовый список
- Поддержка стандартных сущностей (Лид, Сделка, Контакт, Компания, Предложение, Счёт) и смарт-процессов
- Воронки сделок: разные раскладки на разные воронки
- Override-имена: своё название поля только в этой раскладке (не меняя системное)
- Сохранение и сброс раскладки одной кнопкой

## Куда копать дальше

- `index.html` — структура страницы (вкладки/блоки)
- `js/app.js` — корень приложения, инициализация
- `js/demo-data.js` — генератор моков, можно править чтобы поиграться с цифрами
- `js/demo-shim.js` — перехват `fetch('/api/...')` для подмены ответов
- `css/` — стили (большинство в духе Битрикс24)

## Если хочешь сделать реальную интеграцию

Заменить `demo-shim.js` на бэкенд который ходит в Битрикс24 REST:

```
https://<portal>.bitrix24.ru/rest/<user_id>/<webhook_token>/
```

Подробности — на dev.kiselevgroup.com/wiki/ в разделе «Битрикс24 / REST API».
