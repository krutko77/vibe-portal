# app-dina-soglasovanie — Пульт согласований

Канбан-доска для всех типов согласований внутри Битрикс24 — заявки на закупки, договоры, отпуска, командировки. Видно где застряло и кто тормозит.

**Категория:** Согласования · BPM
**Оценка часов:** ~8 часов
**Платформа:** Битрикс24

## Что это

SPA-приложение в Битрикс24, которое заменяет рассылку «согласуй пожалуйста» в чатах и превращает любые заявки на согласование — закупки, договоры, отпуска — в наглядный канбан со статусами и историей.

## Что внутри шаблона

Это **демо-версия** приложения: рабочий UI + синтетические данные.
Бэкенда нет — фронтенд перехватывает все вызовы `/api/*` через `js/demo-shim.js`
и возвращает моки из `js/demo-data.js`. Открывается в браузере без сервера.

## Как открыть

1. На vibe-портале / dev-портале нажми «Создать из шаблона» → `app-dina-soglasovanie`.
2. В VS Code открой `index.html`.
3. Запусти через Live Server (расширение VS Code) или просто открой файл в браузере.

## Фичи (из исходного приложения)

- Канбан со стадиями: Новая → На согласовании → Доработка → Утверждено / Отклонено
- Гибкие типы заявок: закупка, договор, отпуск, командировка, любой свой
- Автоматическое уведомление согласующего в Битрикс24
- История изменений и комментарии по каждой заявке
- Работает внутри портала Битрикс24 как встроенное приложение
- Кастомизация: свои типы заявок, маршруты, поля под ваши процессы

## Куда копать дальше

- `index.html` — структура страницы (вкладки/блоки)
- `js/app.js` — корень приложения, инициализация
- `js/demo-data.js` — генератор моков, можно править чтобы поиграться с цифрами
- `js/demo-shim.js` — перехват `fetch('/api/...')` для подмены ответов
- `css/` — стили (большинство в духе Битрикс24)

## Если хочешь сделать реальную интеграцию

Заменить `demo-shim.js` на бэкенд который ходит в Битрикс24 REST:

```
https://<portal>.bitrix24.ru/rest/<user_id>/<webhook_token>/
```

Подробности — на dev.kiselevgroup.com/wiki/ в разделе «Битрикс24 / REST API».
