# app-contacts24 — Вкладка «Контакты» в карточке компании

Новая вкладка прямо в карточке компании Битрикс24 — все привязанные контакты с поиском, фильтрами, массовым удалением и отвязкой. Без открытия по одному.

**Категория:** CRM · Расширение карточки
**Оценка часов:** ~9 часов
**Платформа:** Битрикс24

## Что это

Новая вкладка прямо в карточке компании CRM. Видны все привязанные контакты сразу: с поиском, фильтрами по должности и ответственному, чекбоксами, массовым удалением и отвязкой. Без открытия каждого контакта по отдельности.

## Что внутри шаблона

Это **демо-версия** приложения: рабочий UI + синтетические данные.
Бэкенда нет — фронтенд перехватывает все вызовы `/api/*` через `js/demo-shim.js`
и возвращает моки из `js/demo-data.js`. Открывается в браузере без сервера.

## Как открыть

1. На vibe-портале / dev-портале нажми «Создать из шаблона» → `app-contacts24`.
2. В VS Code открой `index.html`.
3. Запусти через Live Server (расширение VS Code) или просто открой файл в браузере.

## Фичи (из исходного приложения)

- Вкладка появляется во всех карточках компаний рядом со «Сделками»
- Поиск по фамилии, должности, телефону, email — мгновенно
- Фильтры: ответственный, должность, дата создания, телефон, email
- Чекбоксы и массовые действия: отвязать от компании или удалить
- Прямые ссылки на карточку контакта в один клик
- Работает с любым количеством контактов (постранично, batch API 50/запрос)

## Куда копать дальше

- `index.html` — структура страницы (вкладки/блоки)
- `js/app.js` — корень приложения, инициализация
- `js/demo-data.js` — генератор моков, можно править чтобы поиграться с цифрами
- `js/demo-shim.js` — перехват `fetch('/api/...')` для подмены ответов
- `css/` — стили (большинство в духе Битрикс24)

## Если хочешь сделать реальную интеграцию

Заменить `demo-shim.js` на бэкенд который ходит в Битрикс24 REST:

```
https://<portal>.bitrix24.ru/rest/<user_id>/<webhook_token>/
```

Подробности — на dev.kiselevgroup.com/wiki/ в разделе «Битрикс24 / REST API».
