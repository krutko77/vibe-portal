# Вкладка «Контакты» в карточке компании

Новая вкладка прямо в карточке компании Битрикс24 — все привязанные контакты с поиском, фильтрами, массовым удалением и отвязкой. Без открытия по одному.

## Запуск

Открой `index.html` в браузере (или через **Live Server** в VS Code).
Демо работает с моками — `js/demo-shim.js` перехватывает `/api/*` и
возвращает синтетику из `js/demo-data.js`.

## Подсказки

- Описание для AI-ассистента — в `CLAUDE.md` рядом.
- Чтобы запустить Claude: в терминале VS Code набери `claude`, или
  открой расширение Claude Code в боковой панели.
- Это шаблон с курса **vibe.kiselevgroup.com**.

## Структура

| Файл | Что внутри |
|------|------------|
| `index.html` | разметка страницы |
| `js/app.js` | основная логика |
| `js/demo-data.js` | моковые данные |
| `js/demo-shim.js` | перехват API-вызовов |
