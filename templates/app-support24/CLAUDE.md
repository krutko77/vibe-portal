# app-support24 — Пульт клиентских задач

Канбан задач от клиента + Telegram-канал в одном окне. Видно где зависло, кто негативит, сколько списано часов.

**Категория:** Поддержка · Канбан
**Оценка часов:** ~12 часов
**Платформа:** Битрикс24 / Standalone

## Что это

Открытый канал поддержки клиента в одном окне: задачи из Google Sheet раскладываются по канбану, Telegram-чат подсвечивает негатив, лист учёта рабочего времени связан со сделками. Все 5 представлений работают по одним и тем же данным.

## Что внутри шаблона

Это **демо-версия** приложения: рабочий UI + синтетические данные.
Бэкенда нет — фронтенд перехватывает все вызовы `/api/*` через `js/demo-shim.js`
и возвращает моки из `js/demo-data.js`. Открывается в браузере без сервера.

## Как открыть

1. На vibe-портале / dev-портале нажми «Создать из шаблона» → `app-support24`.
2. В VS Code открой `index.html`.
3. Запусти через Live Server (расширение VS Code) или просто открой файл в браузере.

## Фичи (из исходного приложения)

- Канбан с 6 стадиями: Новая → Анализ → Разработка → Тест → Приостановлена → Закрыта
- Таблица всех задач со всеми колонками + сортировка
- Дашборд: KPI, donut статусов, гистограмма возраста, активность за 14 дней, топ-5 шумных задач
- Telegram-чат с клиентом + автоопределение негатива (сентимент-анализ)
- ЛУРВ: лист учёта рабочего времени, связанный с задачами
- Источник данных — ваша Google-таблица + Telegram-канал клиента

## Куда копать дальше

- `index.html` — структура страницы (вкладки/блоки)
- `js/app.js` — корень приложения, инициализация
- `js/demo-data.js` — генератор моков, можно править чтобы поиграться с цифрами
- `js/demo-shim.js` — перехват `fetch('/api/...')` для подмены ответов
- `css/` — стили (большинство в духе Битрикс24)

## Если хочешь сделать реальную интеграцию

Заменить `demo-shim.js` на бэкенд который ходит в Битрикс24 REST:

```
https://<portal>.bitrix24.ru/rest/<user_id>/<webhook_token>/
```

Подробности — на dev.kiselevgroup.com/wiki/ в разделе «Битрикс24 / REST API».
