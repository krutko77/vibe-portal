# app-parser1c — Парсер 1С → Битрикс24

Выгрузили из 1С → залили xlsx → товары, прайс и остатки в Битрикс24 обновились автоматически. Сотни строк за минуты, не по одной руками.

**Категория:** Интеграция · 1С → Б24
**Оценка часов:** ~18 часов
**Платформа:** Битрикс24 + 1С

## Что это

Принимает Excel или CSV-выгрузку из 1С (товары, прайс, остатки, контрагенты). Сам распознаёт колонки. Массово создаёт и обновляет элементы смарт-процесса в Битрикс24 через batch API. Лог по каждой строке, повторная заливка не дублирует — обновляет по артикулу.

## Что внутри шаблона

Это **демо-версия** приложения: рабочий UI + синтетические данные.
Бэкенда нет — фронтенд перехватывает все вызовы `/api/*` через `js/demo-shim.js`
и возвращает моки из `js/demo-data.js`. Открывается в браузере без сервера.

## Как открыть

1. На vibe-портале / dev-портале нажми «Создать из шаблона» → `app-parser1c`.
2. В VS Code открой `index.html`.
3. Запусти через Live Server (расширение VS Code) или просто открой файл в браузере.

## Фичи (из исходного приложения)

- Принимает .xlsx, .xls, .csv (любая структура колонок)
- Авто-распознавание колонок: Артикул, Наименование, Цена, Остаток, Склад, Категория
- Предпросмотр перед заливкой: видно что прочитал и куда положит
- Массовое создание и обновление через batch API (50 запросов/пакет)
- Дедупликация по артикулу: повторная заливка обновит, а не задвоит
- Лог по каждой строке: создано / обновлено / пропущено / ошибка
- Работает с любым смарт-процессом Битрикс24 (товары, контрагенты, заказы)

## Куда копать дальше

- `index.html` — структура страницы (вкладки/блоки)
- `js/app.js` — корень приложения, инициализация
- `js/demo-data.js` — генератор моков, можно править чтобы поиграться с цифрами
- `js/demo-shim.js` — перехват `fetch('/api/...')` для подмены ответов
- `css/` — стили (большинство в духе Битрикс24)

## Если хочешь сделать реальную интеграцию

Заменить `demo-shim.js` на бэкенд который ходит в Битрикс24 REST:

```
https://<portal>.bitrix24.ru/rest/<user_id>/<webhook_token>/
```

Подробности — на dev.kiselevgroup.com/wiki/ в разделе «Битрикс24 / REST API».
