# app-timepay24 — Часы за зарплату

Сколько часов команда списала, кто грузится больше нормы, какая ЗП по сетке грейдов — отчёт без ручной сводки в Excel.

**Категория:** HR · Часы
**Оценка часов:** ~12 часов
**Платформа:** Битрикс24

## Что это

Каждый сотрудник в Битрикс24 списывает часы по задачам — приложение собирает их в один отчёт по периоду, считает зарплату по сетке грейдов и подсвечивает, кто перегружен, а кто не дотягивает до нормы. Никаких сводок в Excel.

## Что внутри шаблона

Это **демо-версия** приложения: рабочий UI + синтетические данные.
Бэкенда нет — фронтенд перехватывает все вызовы `/api/*` через `js/demo-shim.js`
и возвращает моки из `js/demo-data.js`. Открывается в браузере без сервера.

## Как открыть

1. На vibe-портале / dev-портале нажми «Создать из шаблона» → `app-timepay24`.
2. В VS Code открой `index.html`.
3. Запусти через Live Server (расширение VS Code) или просто открой файл в браузере.

## Фичи (из исходного приложения)

- Таблица сотрудников × дней: видно, кто и сколько часов списал в каждый день месяца
- Сетка грейдов: 60→10к, 70→20к, ... 140→90к — расчёт зарплаты автоматический
- Раздельный учёт мотивационных часов и служебных (✴) — премии только за «полезные»
- Половинный коэффициент для внутренних задач — настраивается под ваши правила
- Графики «часы и зарплата по месяцам» — 12 месяцев истории сразу
- Слайд-овер: клик по ячейке → детализация задач и комментариев за день
- Инкрементальное обновление: «последние 2 дня» обновляются за минуту, не за час

## Куда копать дальше

- `index.html` — структура страницы (вкладки/блоки)
- `js/app.js` — корень приложения, инициализация
- `js/demo-data.js` — генератор моков, можно править чтобы поиграться с цифрами
- `js/demo-shim.js` — перехват `fetch('/api/...')` для подмены ответов
- `css/` — стили (большинство в духе Битрикс24)

## Если хочешь сделать реальную интеграцию

Заменить `demo-shim.js` на бэкенд который ходит в Битрикс24 REST:

```
https://<portal>.bitrix24.ru/rest/<user_id>/<webhook_token>/
```

Подробности — на dev.kiselevgroup.com/wiki/ в разделе «Битрикс24 / REST API».
